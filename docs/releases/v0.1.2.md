# kwick v0.1.2

## Summary

No behavior change to `justBeforeEach`/`JustBeforeEachExtension` -- this
release is entirely build/tooling/packaging. It's this repo's first Maven
Central publishing setup, following `humane-kotlin`'s own `v0.1.0` -> `v0.1.1`
bootstrap exactly.

## Maven Central publishing (new)

Applied [`com.vanniktech.maven.publish`](https://vanniktech.github.io/gradle-maven-publish-plugin/central/)
0.37.0 -- `publishToMavenCentral()` + `signAllPublications()`, coordinates
`com.netpress:kwick`, and the required POM fields (license, SCM, developer).
GPG signing reuses this account's existing Central Portal infrastructure from
`humane-kotlin`'s own setup (namespace verification, user token, GPG keypair
already provisioned for `com.netpress`) -- no second namespace verification
needed, just this repo's own copy of the same credentials as CI secrets.

Added a tag-triggered `publish` job to `CI.yml`, gated on
`startsWith(github.ref, 'refs/tags/v')` and `needs: test`, matching
`humane-kotlin`'s/`kotidy`'s own `CI.yml`.

First publish under this version uses manual publishing (`publishToMavenCentral()`
with no arguments) -- the deployment lands in "Validated" state on the
[Central Portal](https://central.sonatype.com/publishing/deployments) for a
manual "Publish" click, rather than releasing automatically.

## Scope

Still consumed by [`next-caltrain-kotlin`](https://github.com/woodie/next-caltrain-kotlin)
and [`huck`](https://github.com/woodie/huck) via `includeBuild("../kwick")` --
switching both to the published Maven Central artifact is tracked separately
in issue #3, once this release is confirmed live.
